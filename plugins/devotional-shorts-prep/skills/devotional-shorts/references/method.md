# 묵상 쇼츠 콘텐츠 제작 방법론

방법론 버전: `1.1.0`

이 문서는 묵상 본문을 묵상 포인트와 한국어 쇼츠 낭독 원고로 만드는 유일한 런타임 기준이다. 새 작업을 시작할 때 전체를 읽고, 작업 데이터에는 버전과 이 파일 바이트의 SHA-256을 기록한다.

## 1. 입력 계약

### 필수 입력

- 묵상 본문 전문

공백만 있는 본문은 거부한다. 성경 장절만 있고 본문 전문이 없으면 전문 입력을 요청한다.

### 선택 입력

- 본문 위치
- 작업 제목
- 묵상 기준일
- 특별히 강조할 신학적 관점
- 특정 독자 또는 상황
- 시각 방향 또는 화풍

본문 위치가 없으면 `본문 위치 미확인`으로 표시한다. 본문 내용만으로 책·장·절을 추측하지 않는다.

## 2. 본문 해석 원칙

1. 본문 전체의 문학적 단락과 사건 또는 논리 흐름을 먼저 파악한다.
2. 처음 듣는 사람이 이해하는 데 필요한 앞뒤 문맥만 설명한다.
3. 당시 청중, 장소, 역사적 배경은 본문 이해에 기여하는 범위에서만 사용한다.
4. 복음주의적 성경 이해를 기본으로 한다.
5. 그리스도 중심 적용은 본문 또는 정경적 연결이 실제로 뒷받침할 때만 사용한다.
6. 본문에 없는 행동, 감정, 동기, 시대 정보를 사실로 만들지 않는다.
7. 인물의 행동이 기록되어 있어도 그 사람의 내면 동기, 믿음의 깊이, 감정은 본문이 밝히지 않으면 단정하지 않는다.
8. 바로 앞뒤 문맥이 해석 방향을 실질적으로 바꿀 수 있으면 확인한다. 여러 책임 있는 해석이 가능한 본문은 공통으로 확인되는 의미를 중심에 두고 한 해석을 유일한 뜻처럼 말하지 않는다.

### 근거 수준

| 범주 | 의미 | 표현 원칙 |
| --- | --- | --- |
| 본문 | 입력 본문이 명시한 사실과 표현 | 본문 범위에서 단정 가능 |
| 해석 | 문맥과 복음주의적 주해로 설명한 의미 | 근거가 드러나게 설명 |
| 추론 | 본문에 직접 없지만 정황에서 도출한 설명 | `보인다`, `생각할 수 있다`, `시사한다` 사용 |
| 적용 | 오늘의 삶과 신앙에 연결한 질문과 실천 | 본문 의미에서 출발 |

보고서와 원고는 자연스럽게 이어 쓰되, 추론을 본문 사실처럼 단정하지 않는다.

핵심 묵상 문장은 본문이 명시한 사실 또는 본문에서 직접 설명할 수 있는 해석만 중심 주장으로 사용한다. 인물의 내면과 동기를 전제로 해야 성립하는 문장은 핵심 문장으로 선택하지 않는다. 필요한 추론은 `이 장면은 … 생각하게 한다`, `…로 묵상할 수 있다`처럼 추론임을 들리게 표현한다.

## 3. 묵상 포인트

다음 다섯 항목을 순서대로 작성한다.

1. **본문 배경**: 필요한 인물, 사건, 앞뒤 문맥을 2~4문장으로 설명한다.
2. **핵심 해석**: 본문이 드러내는 하나님, 인간, 믿음 또는 복음의 의미를 설명한다.
3. **핵심 묵상 문장**: 전체 원고를 관통하는 한 문장을 작성한다.
4. **오늘의 적용**: 현대인이 겪는 구체적 상황과 연결한다.
5. **적용 질문**: 시청자가 자신을 돌아보게 하는 질문 1~2개를 제시한다.

핵심 묵상 문장은 기억하기 쉬워야 하지만 본문을 과장하거나 자기계발 표어로 바꾸면 안 된다.

오늘의 적용에는 시청자가 오늘 또는 이번 주에 실행할 수 있는 낮은 위험의 행동을 하나 이상 넣는다. `작은 순종`, `내려놓기`, `믿기`처럼 측정할 수 없는 말만 남기지 않고 언제, 무엇을, 어떻게 할지를 짧게 밝힌다.

돈, 가난, 질병, 학대, 권력관계처럼 취약한 청자에게 해를 줄 수 있는 본문은 다음을 함께 지킨다.

- 식비, 주거비, 치료비와 같은 필수 필요를 해치거나 빚을 내도록 권하지 않는다.
- 헌금, 용서, 인내, 복종을 타인의 압박이나 위험을 견디라는 명령으로 사용하지 않는다.
- 본문이 취약한 사람의 희생을 기록한다는 이유만으로 같은 희생을 시청자에게 직접 요구하지 않는다.
- 안전 문구만 덧붙이고 다시 위험한 행동을 암시하지 않는다. 적용 자체를 안전한 행동으로 설계한다.

## 4. 오프닝 질문

### 후보 생성

- 핵심 묵상 문장에 근거한 서로 다른 질문을 정확히 10개 만든다.
- 경험, 두려움, 선택, 관계, 믿음 등 서로 다른 각도를 사용한다.
- 예·아니오로 끝나는 같은 형식만 반복하지 않는다.
- 첫 3초 안에 이해할 수 있는 낭독 문장으로 쓴다.

### 평가 기준

| 기준 | 배점 |
| --- | ---: |
| 본문과 핵심 문장 충실도 | 30 |
| 첫 3초의 호기심 | 25 |
| 신자·비신자 접근성 | 20 |
| 낭독 자연스러움 | 15 |
| 선정적 왜곡이 없음 | 10 |

각 후보를 100점 만점으로 평가한다. 최고 점수 한 개를 최종안으로, 선택안을 제외한 다음 세 개를 대안으로 보고한다. 동점이면 충실도, 접근성, 낭독 자연스러움 점수 순으로 결정한다.

## 5. 썸네일 문구

### 후보 생성

- 핵심 묵상 문장을 압축한 서로 다른 문구를 정확히 10개 만든다.
- 한 화면에서 즉시 이해되는 짧은 구로 쓴다.
- 마침표를 붙이지 않는다.
- 본문에 없는 공포, 성공, 심판을 과장하지 않는다.

### 평가 기준

| 기준 | 배점 |
| --- | ---: |
| 본문과 핵심 문장 충실도 | 30 |
| 즉시 이해 가능성 | 25 |
| 간결성 | 20 |
| 호기심 | 15 |
| 과장·공포 조장이 없음 | 10 |

오프닝과 같은 방식으로 최고 점수 한 개와 대안 세 개를 선택한다. 동점이면 충실도, 즉시 이해 가능성, 간결성 점수 순으로 결정한다.

## 6. 스크립트 구조

다음 순서를 바꾸지 않는다.

1. 핵심 문장
2. 썸네일 문구
3. 오프닝 질문 1~2줄
4. 본문으로 연결하는 다리 문장
5. 처음 듣는 사람에게 필요한 경우 본문 배경 2줄 이내
6. 기본 3줄의 본문 요약과 확인 가능한 장절 표기
7. 본문 해석과 삶의 적용
8. 핵심 문장 재강조와 적용 질문
9. 3줄 이내의 짧은 기도
10. 고정 CTA

본문의 맥락을 3줄로 줄이면 의미가 손상될 때만 본문 요약을 늘리고 분량 검사에서 다시 압축한다.

### 고정 CTA

다음 문장을 문자 그대로 사용한다.

> 이 영상이 도움이 되셨다면 좋아요와 구독으로 응원해주시고, 생각난 분들에게 이 영상을 공유해주시기 바랍니다.

## 7. 문체와 낭독성

- 한국어 낭독형 설교체로 쓴다.
- 문장 끝은 `다`, `나`, `까`를 사용한다.
- `요`, `요.`, `요?`, `요!`로 문장을 끝내지 않는다.
- 친근하지만 지나치게 사적인 친구 말투를 피한다.
- 신자와 비신자가 함께 이해하도록 신학 전문용어를 풀어 쓴다.
- 한 문장에 의미를 너무 많이 연결하지 않는다.
- 본문 요약은 눈앞에 그려지게 구체적으로 쓰되 없는 장면을 만들지 않는다.
- `드림`, `맡김`, `순종 한 걸음`처럼 문법상 가능해도 구어에서 뜻이 걸리는 명사화를 피하고 소리 내어 한 번 읽어 자연스러운 동사 문장으로 고친다.
- 결론에서 핵심 문장을 다시 들려주고 시청자의 삶을 향한 질문으로 끝맺는다.

## 8. 분량

- 공백을 제외한 한글·영문·숫자 5자를 낭독 1초로 추정한다.
- 목표는 100~120초다.
- 120초를 넘으면 중복 설명, 수식어, 반복 적용 순으로 줄인다.
- 필수 배경을 제거하면 초심자의 이해가 훼손될 때만 121~150초를 허용한다.
- 예외를 사용하면 `duration_exception: true`와 한 문장 사유를 보고한다.
- 150초를 넘는 원고는 완료 결과로 내보내지 않고 다시 압축한다.

시간 추정에는 실제 낭독문만 포함한다. 제목, 후보 목록, 평가 점수, 출처 표시는 제외한다.

## 9. 성경 장절

- 현재 본문의 성경 안에서 인용할 때는 책 이름을 반복하지 않는다. 같은 장은 `(1-3절)`, 다른 장까지 포함하면 `(22:51, 23:8-10)`처럼 장절만 쓴다.
- 다른 성경은 `(롬 5:8)`처럼 통용 약칭과 장절을 함께 쓴다.
- 입력과 확인 가능한 근거에 없는 장절을 만들지 않는다.
- 보조 구절은 핵심 해석을 실제로 뒷받침할 때만 사용한다.

본문 요약의 각 문장에 장절을 붙여야 한다면 `시편 23편 1절에서`처럼 책 이름을 되풀이하지 말고 `여호와가 나의 목자라고 고백한다(1절)`처럼 쓴다.

## 10. 외부 인용

- 신학자, 목회자, 작가, 유명인의 직접 인용은 원문과 저자·출처를 확인할 수 있을 때만 사용한다.
- 저자, 출처명, 확인 URL 또는 서지정보를 함께 기록한다.
- 번역한 인용은 번역임을 표시하고 원문의 의미를 과장하지 않는다.
- 기억에 의존하거나 출처를 확인할 수 없으면 인용을 생략한다.
- 인용이 없어도 스크립트를 완결되게 작성한다.

## 11. 지시 우선순위

충돌 시 다음 순서를 사용한다.

1. 사실 검증과 승인 안전 규칙
2. 현재 작업에 사용자가 명시한 특별 지시
3. 이 버전의 제작 방법론
4. 승인 예시에서 관찰되는 선호
5. 일반적인 작성 선호

사용자의 신학적 강조는 본문과 충돌하지 않는 범위에서 반영한다. 화풍 지시는 콘텐츠 의미를 바꾸지 않는다.

## 12. 수정

1. 변경 대상과 보존 대상을 먼저 구분한다.
2. 사용자가 변경하지 말라고 한 섹션은 문자 그대로 보존한다.
3. 핵심 의미가 바뀌면 오프닝, 썸네일, 해석, 적용 등 종속 섹션을 다시 계산한다.
4. 좁은 문구 수정은 해당 섹션만 바꾼다.
5. 수정 결과 전체에 완료 검사를 다시 수행한다.
6. 변경된 섹션을 보고하고 새 승인을 요구한다.

## 13. 완료 검사

아래 항목을 순서대로 확인하고 실패 항목만 한 번 수정한다.

- [ ] 본문 전문이 존재한다.
- [ ] 본문, 해석, 추론, 적용의 근거 수준을 혼동하지 않는다.
- [ ] 본문이 밝히지 않은 인물의 내면·동기·믿음의 깊이를 단정하지 않는다.
- [ ] 해석에 중요한 앞뒤 문맥과 책임 있는 대안 해석을 무시하지 않는다.
- [ ] 묵상 포인트 다섯 항목이 순서대로 존재한다.
- [ ] 오프닝 후보 10개가 실질적으로 서로 다르다.
- [ ] 오프닝 최종안 1개와 대안 3개가 있다.
- [ ] 썸네일 후보 10개가 실질적으로 서로 다르다.
- [ ] 썸네일 최종안 1개와 대안 3개가 있다.
- [ ] 스크립트 열 항목이 순서대로 존재한다.
- [ ] 문장 종결에 `요`체가 없다.
- [ ] 고정 CTA가 문자 그대로 존재한다.
- [ ] 현재 본문과 같은 책의 장절에는 책 이름을 반복하지 않고, 다른 책의 장절에는 약칭을 포함한다.
- [ ] 미확인 장절과 인용 출처를 만들지 않는다.
- [ ] 예상 시간이 120초 이하이거나 150초 이하의 예외 사유가 있다.
- [ ] 오늘 또는 이번 주에 실행할 수 있는 구체적이고 낮은 위험의 행동이 하나 이상 있다.
- [ ] 취약한 청자에게 필수 필요를 포기하거나 위험을 견디도록 압박하지 않는다.
