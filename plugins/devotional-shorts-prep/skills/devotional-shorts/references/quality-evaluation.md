# 의미 품질 평가 계약

구조 검사를 통과할 수 있는 초안도 본문을 왜곡하거나 위험한 적용을 만들 수 있다. 담당자 보고 전에 입력 본문, 필요한 앞뒤 문맥, 묵상 포인트, 전체 낭독문을 함께 놓고 이 계약으로 평가한다.

## 평가 절차

1. 초안의 중심 주장마다 `본문`, `해석`, `추론`, `적용` 중 근거 수준을 확인한다.
2. 아래 다섯 축을 각각 1~5점의 정수로 평가하고 한 문장 근거를 남긴다.
3. 본문에 없는 사실·내면·동기를 단정한 문구와 위험한 적용을 정확히 인용한다.
4. 한 축이라도 4점 미만이거나 평균이 4.2점 미만이면 실패한 축만 한 번 수정한다.
5. 수정 뒤 구조 검사와 의미 품질 평가를 모두 다시 수행한다. 다시 실패하면 보고·저장하지 않는다.

## 다섯 평가축

| 축 | 4점 이상 기준 |
| --- | --- |
| 본문 충실도 | 본문의 명시적 사실과 필요한 문맥을 보존하고, 기록되지 않은 내면·동기를 단정하지 않는다. |
| 해석 명료성 | 본문, 책임 있는 해석, 추론, 오늘의 적용이 듣는 사람에게 구분된다. |
| 복음주의적 일관성 | 본문에 근거한 하나님·인간·믿음 이해를 제시하며 은혜를 지우거나 행위의 크기로 신앙을 재지 않는다. |
| 낭독 자연스러움 | 소리 내어 한 번에 이해되며 어색한 명사화, 긴 연결, 낯선 전문어가 없다. |
| 적용 구체성 | 오늘 또는 이번 주에 실행할 대상·행동·시점이 있고, 취약한 청자에게 해로운 행동을 압박하지 않는다. |

## 점수 원칙

- 5점: 고칠 의미상 결함이 없고 다른 본문에도 기준 사례로 쓸 수 있다.
- 4점: 담당자에게 보고 가능한 수준이며 남은 개선은 취향에 가깝다.
- 3점: 중심 의미는 이해되지만 본문 비약, 모호한 적용, 낭독 장애 중 하나가 실질적으로 남는다.
- 2점: 중심 주장이나 적용을 다시 써야 한다.
- 1점: 본문 왜곡, 신학적 충돌, 명백한 위해 가능성 때문에 사용할 수 없다.

## 즉시 실패 조건

다음 중 하나라도 있으면 평균과 관계없이 실패한다.

- 본문이 밝히지 않은 인물의 믿음, 동기, 감정을 사실처럼 중심 주장으로 사용한다.
- 책임 있는 앞뒤 문맥을 무시해 본문 의미를 반대로 만들거나 하나의 논쟁적 해석만 사실로 단정한다.
- 필수 생활비 포기, 빚, 치료 중단, 학대 인내처럼 청자에게 현실적 위해를 줄 행동을 권한다.
- 출처가 검증되지 않은 직접 인용이나 입력에서 확인할 수 없는 장절을 사용한다.
- 복음의 은혜보다 헌신의 크기나 성취를 하나님께 인정받는 조건으로 제시한다.

점수는 보고를 통과시키기 위한 자기확신이 아니라 수정 대상을 찾는 도구다. 근거를 설명할 수 없는 4점이나 5점은 사용하지 않는다.
