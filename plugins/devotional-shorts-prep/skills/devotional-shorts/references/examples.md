# 승인 예시 등록부

이 문서는 담당자가 승인한 실제 원고의 스타일 근거를 보존한다. 현재 등록된 승인 예시는 없다. 예시가 없더라도 `method.md`만으로 모든 콘텐츠 생성 규칙이 결정된다.

## 사용 원칙

- 승인 예시는 규칙이 아니라 스타일 증거다.
- 한 사례의 표현을 다른 본문에 기계적으로 복사하지 않는다.
- 반복 가능한 새 규칙은 예시가 아니라 `method.md`에 반영하고 방법론 버전을 올린다.
- 본문 원문을 저장할 권한이 있는 사례만 등록한다.
- 실제 담당자 이름, 텔레그램 ID, 비공개 메모는 기록하지 않는다.

## 등록 형식

새 예시는 다음 항목을 모두 포함한다.

```markdown
## EX-YYYY-NNN — 짧은 식별 제목

- 방법론 버전: 예시가 승인된 시점의 버전
- 본문 위치: 확인된 경우만 기록
- 입력 본문: 저장 권한이 있는 원문 또는 허용된 참조
- 핵심 묵상 문장: 승인된 문장
- 선택 오프닝: 승인된 질문
- 선택 썸네일: 승인된 문구
- 최종 스크립트: 승인된 전체 원고
- 승인 근거: 담당자가 좋다고 판단한 구체적 특성
- 재사용 가능한 특성: 리듬, 전환, 설명 밀도 등
- 본문 한정 특성: 다른 본문에 일반화하면 안 되는 내용
```

예시 식별자의 연도는 승인 연도, 번호는 등록 순서의 세 자리 숫자를 사용한다. 기존 예시는 수정하지 않고 설명 보완이 필요하면 같은 항목 아래에 날짜가 있는 주석을 추가한다.

## 등록 수용 기준

- 담당자가 현재 리비전을 명확히 승인했다.
- 입력과 최종 원고의 관계를 검토할 수 있다.
- 본문에 없는 사실이나 검증되지 않은 직접 인용이 없다.
- 묵상 포인트와 스크립트 필수 구조가 있다.
- 방법론에서 재사용할 특성과 해당 본문에만 한정된 특성을 구분했다.
