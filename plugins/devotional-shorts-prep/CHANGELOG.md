# 변경 이력

이 프로젝트는 [Semantic Versioning](https://semver.org/)을 따른다.

## 1.0.1 — 2026-09-08

운영 안전성과 ZIP 단독 설치 문서를 보완한 패치 릴리스다.

### 수정

- Telegram preflight에서 outgoing webhook 충돌을 감지하고 전송 없이 중단
- 봇 전체 업데이트 큐에서 답장을 잃지 않도록 승인 대기 작업을 하나로 제한
- Telegram 전송 계열 요청의 불확실한 네트워크 실패를 자동 재시도하지 않아 중복 가능성 축소
- 429 응답의 `retry_after`를 한국어 복구 안내에 반영
- 현재 보고서의 `확인이 필요한 사항`을 Telegram 요약에 표시하면서 이전 보고서 형식도 지원
- ZIP에 운영 런북을 포함하고 ZIP 내부에서 깨지는 개발 문서 링크 제거

### 호환성

- 콘텐츠 방법론 `1.1.0`, 방법론 해시, 작업 데이터 스키마 `1` 유지
- 기존 `1.0.0` 작업과 ZIP 설치·원자적 업데이트 경로 유지

## 1.0.0 — 2026-08-13

첫 정식 릴리스다.

### 기능

- 본문 기반 묵상 포인트, 후보 평가, 약 2분 분량 낭독 원고와 장면별 이미지 계획 생성
- 리비전별 작업 저장, 의미 품질 검사, Telegram 보고·승인·수정·보류 처리
- 승인 후 ImageGen 생성, 실패 장면 재개, Telegram 이미지 전달
- 결정적 ZIP, SHA-256 체크섬, 배포 보안 감사와 원자적 설치·업데이트

### 호환성

- 콘텐츠 방법론 `1.1.0`과 SHA-256 `1684b969e1822d2cd41eb7a485201871339cd04203557ff13e2b684bb6847ae5` 유지
- 작업 데이터 스키마 `1` 유지
- `0.9.0`에서 만든 작업은 저장된 방법론 스냅샷으로 계속 검증 가능

### 보안

- Telegram 토큰·그룹 ID·승인자 ID는 환경변수에서만 읽음
- `.env`, `jobs/`, `source-materials/`, 생성 이미지와 사용자 홈 절대경로를 배포물에서 제외
- 현재 리비전과 승인 메시지·담당자·콘텐츠 해시가 일치하기 전 이미지 생성 차단

### 알려진 범위

- 상시 승인 감시, 웹 UI, 데이터베이스, YouTube 업로드, 음성·자막·영상 렌더링은 포함하지 않음
- 각 사용자가 자신의 Telegram 봇·그룹·승인자 환경변수를 설정해야 함
