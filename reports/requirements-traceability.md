# 요구사항 추적표

문서 01의 요구사항을 구현 세션과 최종 검증에 연결한다. 상태는 `기반`, `구현`, `검증`, `검증(모의)`, `검증(외부)` 중 하나이며 세션 종료 보고서의 증거가 있을 때만 갱신한다. `검증(모의)`는 외부 API 자격 증명이 필요한 경계를 모의 전송과 호출 계약으로만 통과한 상태이며, `검증(외부)`는 실제 Telegram 또는 ImageGen 경계까지 인수한 상태다.

아래 상태는 세션 09의 외부 인수 이력을 보존한다. `1.0.1`에서는 원본·격리 설치본 테스트가 각각 71개 통과했으며, 이번 보완 중 실제 Telegram·ImageGen 외부 호출은 수행하지 않았다.
