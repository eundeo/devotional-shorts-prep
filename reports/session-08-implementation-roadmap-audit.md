## 구현 중 발견하여 세션 안에서 수정한 항목

1. 깨끗한 설치본에서 전체 테스트를 실행하면 저장소 루트의 마켓플레이스 파일을 강제하는 테스트가 실패했다. 설치본은 자체 생성 가능한 마켓플레이스 계약만 검사하고, 저장소 원본이 있을 때 실제 파일과도 대조하도록 수정했다.
2. 체크섬 파일은 ZIP 파일명만 기록하므로 다른 현재 폴더에서 실행하면 파일을 찾지 못했다. README에 배포 파일 폴더에서 체크섬을 실행하도록 명시했다.
3. 처음에는 플러그인 버전을 `X.Y.Z`로만 제한해 공식 로컬 개발 캐시버스터 절차와 충돌했다. 런타임 감사·검증은 `+codex.<값>`을 허용하고, 배포 ZIP은 캐시버스터 없는 출시 버전만 허용하도록 경계를 분리했다.
4. Codex 공식 설치 캐시는 플러그인 내용물을 `.../devotional-shorts-prep/0.7.0/`에 둔다. 소스 폴더명과 매니페스트 이름의 일치를 런타임에도 강제해 캐시 감사가 실패했다. 고정 플러그인 식별자를 검사하도록 바꾸고 버전명 캐시 폴더 회귀 테스트를 추가했다.
5. 사용자 설치 대상이 심볼릭 링크이면 검증 범위 밖 경로를 교체할 수 있었다. 설치·업데이트 전에 대상 링크를 명시적으로 거부하고 부정 테스트로 고정했다.

모든 항목은 최종 패키지 생성 전에 수정하고 자동 또는 독립 시험으로 다시 확인했다.
