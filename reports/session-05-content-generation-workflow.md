## 구현 중 발견하여 세션 안에서 수정한 항목

1. 처음 구현한 수정 흐름은 같은 멱등 키를 현재 리비전 기준으로 다시 비교해 보고서 서명이 달라질 수 있었다. 기존 이벤트가 가리키는 원래 기준 리비전으로 재계산하고 콘텐츠·보고서·방법론·피드백 서명을 모두 비교하도록 수정했다.
2. 독립 사용 시험에서 스킬 문서의 `scripts/...` 예시가 플러그인 루트 기준이라는 점이 명시적이지 않았다. 스킬과 생성 계약에 `SKILL.md`보다 두 디렉터리 위의 플러그인 루트를 해석하도록 추가했다.
3. 본문 위치가 없을 때 경고만 추가하면 모델이 숫자 장절을 생성한 결과를 놓칠 수 있었다. `21:1-4`, `3절` 형태를 저장 전에 거부하도록 보강했다.
4. 보고서에 자체 검수 결과가 없었다. 검토 요약에 `자체 검수: 통과`를 추가하고 템플릿 미해결 필드 검사를 연결했다.

모든 항목은 세션 종료 전에 회귀 테스트로 고정했다.
